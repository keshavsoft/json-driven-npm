Why pass a handler?

The route builder creates functions; the executor decides what they do.

The route engine should not need to know how requests are executed. So the composition root passes an executor function into the route builder. Each generated leaf remembers its own route path and calls that shared executor when invoked.

The composition root supplies the executor

createRoute({
  inApiPaths: apiPaths,
  inSource: source,
  inExecutor: execute
});

Each leaf delegates to it

return async (inParam, ...inArgs) => {
  return await localExecutor({
    inRoutePath: localPath,
    inParam,
    inArgs,
    inSource: localSource
  });
};

The leaf function closes over its route path and the shared executor. That remembered context is a JavaScript closure.

Remember

The executor is injected behavior. The route engine stays reusable because it does not hardcode the execution strategy.

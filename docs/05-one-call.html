Follow one API call

What happens when a developer calls app.founder.profile.fetch()?

The developer sees a simple function call. Behind it, the generated leaf function already knows which route it represents and forwards the call into the common execution pipeline.

The call

const profile = await app.founder.profile.fetch();
1 · ConsumerCalls the nested function.
2 · Generated leafSupplies its remembered route path: app.founder.profile.fetch.
3 · ExecutorReceives route path, input arguments, and source JSON.
4 · DispatcherReturns the configured data or a mock result.
5 · ConsumerReceives the returned value.
Remember

The nested API feels hand-written, but the route functions were assembled automatically at initialization.

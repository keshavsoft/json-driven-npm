JSON-DRIVEN NPM · FIELD GUIDE 03/07

Build the object tree

A string path becomes nested JavaScript properties.

The route engine reads each allowed path, splits it at the dots, creates branch objects, and places a function at the final property. It does this in memory. It does not create folders or files on disk.

Input path

app.founder.profile.fetch

In-memory result

{
  app: {
    founder: {
      profile: {
        fetch: [callable function]
      }
    }
  }
}
1 · route/index.jsLoops over every path in api.json.
2 · attachPath.jsCreates the intermediate objects: app, founder, profile.
3 · createLeafHandler.jsCreates the callable function at fetch.
Remember

The route engine is an object-tree builder, not a file generator.

Understand the engine, one small idea at a time.

A friendly guide to what json-driven-npm does, why it has two JSON files, and how one function call travels through the code.

The whole idea in one sentence

Two JSON files describe the public paths and endpoint data; a route engine turns those paths into callable JavaScript functions; one shared executor handles each call.

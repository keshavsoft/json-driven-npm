JSON-DRIVEN NPM · FIELD GUIDE 07/07

Customize and grow

Add endpoints through JSON; change shared behavior in one place.

To add a new endpoint, define it in source.json and expose its path in api.json. The route engine will mount it the next time the package is initialized.

1 · Describe itAdd the endpoint metadata and optional data to source.json.
2 · Expose itAdd its dot-separated path to api.json.
3 · Use itCall the matching nested function from the imported app object.

Where future changes belong

  • New endpoint: JSON definitions.
  • New public path: api.json.
  • Input rules: validateInput.js.
  • How endpoint metadata is found: getEndpointSpec.js.
  • How the result is produced: dispatchMock.js / dispatch layer.
  • How paths become functions: route engine.

Keep the boundary clear: this package currently builds a JavaScript client object. A future Hono server builder would be a separate adapter or project, not something this package already does.

Remember

The architecture is valuable because endpoint count can grow without endpoint-specific JavaScript boilerplate.
